# rmathrs

Arbitrary precision arithmetic and mathematics library in Rust designed for multi-target compilation (macOS, Windows, Linux, and WebAssembly).

## Targets Supported
- **Native (macOS, Windows, Linux)**: via standard Rust toolchain (`rlib`)
- **WebAssembly (`wasm32-unknown-unknown`)**: via `wasm-pack` and `wasm-bindgen` (`cdylib`)
